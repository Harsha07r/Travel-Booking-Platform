# Royal Horizon — Frontend

React + Vite frontend for the Royal Horizon Travel Booking Platform.

## Quick Start

```bash
npm install
npm run dev
```

The dev server starts at `http://localhost:5173`.

## Environment Variables

Create `.env` in this folder:

```env
VITE_API_BASE_URL=http://localhost:5000
VITE_API_URL=https://your-deployed-backend.onrender.com
```

## Project Structure

- `src/Components/` — Reusable UI components and homepage sections
- `src/Pages/` — Route-level pages (Login, Register, Admin, Tours)
- `src/Contexts/` — Global state (AuthContext)
- `src/Styles/` — CSS files

See the [root README](../README.md) for full project documentation.
